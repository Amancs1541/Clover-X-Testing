  • Identity governance

    SecuritySoftware2026 – present

    AccessPilot: identity governance platform

    A governance layer over Entra ID, Okta and Active Directory that controls who has access to what, for how long, and under whose approval.

    Aman Varma · personal project

    • Python / FastAPI
    • PostgreSQL
    • React / TypeScript
    • Graph API
    • Okta
    • LDAPS
    Code for AccessPilot on GitHub (opens in new tab) Architecture reference (opens in new tab)
    Read case study: AccessPilot

    Problem

    Directories like Entra ID, Okta or Active Directory handle authentication, but none provides an end-to-end request, approval, activation, expiry and review lifecycle across several directories.

    Approach

    FastAPI backend with PostgreSQL and a React/TypeScript frontend. One shared connector interface for Entra ID (Graph API), Okta, Active Directory (LDAPS) and CSV/HR feeds, with a joiner-mover-leaver engine, access packages, business roles, multi-stage approvals, separation of duties, access reviews and audit logging on top.

    Result

    A working governance platform with HR sync, multi-directory provisioning, self-healing background workers and break-glass access, documented in a full architecture reference.

  • Email security

    SecurityWeb Apps2025

    PhishIntel Analyzer

    A web app that scores suspicious .eml files by combining an NLP model, rule-based heuristics and threat-intelligence lookups.

    Aman Varma · security project

    • Python
    • Flask
    • NLP
    • Threat intelligence
    Code for PhishIntel Analyzer on GitHub (opens in new tab) Article on Medium (opens in new tab)
    Read case study: PhishIntel Analyzer

    Problem

    Assessing suspicious emails quickly and explainably needs more than a single detection method.

    Approach

    A Flask app that parses .eml files and combines three methods: a pre-trained NLP model, rule-based header and URL heuristics, and threat-intelligence integration.

    Result

    Each email is scored using all three methods, documented in an article and a project report.
